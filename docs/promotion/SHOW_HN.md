# Show HN: mDIR — a fast dual-pane file manager for Windows and Ubuntu

Hi HN,

I built mDIR because I wanted the direct, keyboard-friendly workflow of the
classic DOS file managers I grew up with, but on modern Windows and Ubuntu.

It is a free and open-source dual-pane file manager with:

- background loading for directories with tens of thousands of files;
- image, PDF, and spreadsheet preview;
- cancellable copy, move, delete, ZIP, search, and batch rename operations;
- compact overwrite warnings and Trash/Recycle Bin support;
- both keyboard-first controls and practical mouse selection; and
- an optional AI command panel, which can be ignored entirely if you do not
  need it.

There are two editions with the same core workflow:

- Windows: https://github.com/jtl-sun/mdir-p
- Ubuntu: https://github.com/jtl-sun/mdir-u

mDIR is a tribute to Choi Jung Han, the developer of the legendary Korean
DOS-era file manager MDIR. I am not trying to turn it into a paid product. My
goal is simply to make everyday file management easier for Windows and Ubuntu
users.

I would especially appreciate feedback on installation, mouse selection, and
performance in very large directories. What would make a terminal file
manager useful enough for you to keep installed?
