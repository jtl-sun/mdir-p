# Windows·Ubuntu용 무료 파일 관리자 mDIR을 공개했습니다

안녕하세요. Windows와 Ubuntu에서 빠르고 편하게 파일을 관리할 수 있는
무료 오픈소스 프로그램 **mDIR**을 만들고 있습니다.

mDIR은 두 개의 패널을 나란히 보면서 복사·이동·이름 변경·삭제를 처리하는
파일 관리자입니다. 예전 MDIR과 Total Commander의 빠른 작업 방식을
좋아하는 분들이 현대적인 터미널에서도 비슷한 감각으로 사용할 수 있도록
만들었습니다.

주요 기능은 다음과 같습니다.

- 파일이 수만 개 있는 폴더도 백그라운드에서 불러오기
- 이미지, PDF, Excel 미리보기
- 취소 가능한 복사·이동·삭제와 안전한 덮어쓰기 경고
- 검색, ZIP 압축/해제, 여러 파일 이름 한꺼번에 변경
- 키보드와 마우스를 함께 사용할 수 있는 두 패널 UI
- 필요할 때만 켤 수 있는 선택형 AI 명령 패널

유료 판매나 구독 서비스가 목적이 아닙니다. Windows와 Ubuntu 사용자가
파일을 조금 더 쉽고 빠르게 관리할 수 있었으면 하는 마음으로 MIT
라이선스로 공개했습니다.

- Windows mDIR-P: https://github.com/jtl-sun/mdir-p
- Ubuntu mDIR-U: https://github.com/jtl-sun/mdir-u

설치 과정, 대용량 폴더 속도, 마우스 선택 방식에 대한 의견을 특히 듣고
싶습니다. 사용 중 불편한 점은 GitHub Issues에 편하게 남겨 주세요.

※ 프로그램과 관계없는 홍보성 댓글이나 과장된 표현은 지양하고, 각
커뮤니티의 게시 규칙에 맞게 제목과 문장을 조정해 사용하세요.
