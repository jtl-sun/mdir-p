# mDIR: a free dual-pane file manager for Windows and Ubuntu

I have released mDIR, a free and open-source dual-pane file manager for people
who prefer seeing the source and destination at the same time.

It combines the fast workflow of classic file managers with modern features:

- responsive background loading for very large folders;
- image, PDF, and spreadsheet preview;
- cancellable copy, move, delete, archive, search, and batch rename jobs;
- overwrite warnings and platform-native Trash/Recycle Bin behavior;
- keyboard-first shortcuts plus practical mouse controls; and
- an optional AI command panel.

The two editions share the same workflow:

- mDIR-P for Windows: https://github.com/jtl-sun/mdir-p
- mDIR-U for Ubuntu: https://github.com/jtl-sun/mdir-u

The project is MIT licensed, with no subscription, advertising, or account
requirement. It is a personal tribute to Choi Jung Han, creator of the
legendary DOS-era MDIR.

Feedback is welcome, especially about installation, large-directory
performance, and mouse selection. If you try it, please open a GitHub issue
with your operating system and terminal version when reporting a problem.
