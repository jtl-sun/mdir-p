# mDIR-P Project Direction

## Identity

mDIR-P is a modern dual-pane file manager inspired by the directness and accessibility of DOS-era Mdir-style workflows. It is not intended to replace or claim the historical Mdir III identity.

## Version policy

- Keep public versions in the `V2.xx.xx` series.
- Do not move the project to V3.x.
- Increment patch/minor components inside the V2 line for future releases.

## Platform goals

1. Make file management easier for users who find Linux file workflows inconvenient.
2. Remain comfortable to launch and use from Windows Terminal and PowerShell.
3. Preserve keyboard-first speed while keeping mouse operations intuitive.
4. Keep dual-pane independence and predictable file-operation safety.

## Modern core features

- **AI/File**: contextual AI assistance without turning the file manager into an AI-only interface.
- **File View / Preview**: fast viewing of images, PDF and Office documents without unnecessary application switching.
- **File Search**: fast search, indexing and discovery as a first-class file-management workflow.

## UX principle

Features should be discoverable at a glance, fast from the keyboard, and usable with one obvious mouse action. New visual features must not reduce selection clarity, file-operation safety or large-folder performance.

## old_M_tema

`old_M_tema` is a visual homage to classic DOS file-manager readability: black workspace, cyan/teal chrome, strong cursor contrast and extension-specific colors. The modern mDIR-P layout, Preview, Search, thumbnails, progress windows and AI features remain unchanged.
